# Especificación: Actualización de selectores Auth en pruebas E2E

Se actualizarán los archivos de pruebas E2E para reemplazar referencias a campos "usuario" por "username" donde aplica, para mantener la consistencia con el contrato API de autenticación y erradicar entropía heredada.
