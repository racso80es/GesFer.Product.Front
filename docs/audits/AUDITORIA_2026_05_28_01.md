2. Pain Points (🔴 Críticos / 🟡 Medios)
Hallazgo: [Advertencias `act(...)` en pruebas unitarias]
En las pruebas unitarias, especialmente `src/__tests__/app/login/page.test.tsx` y `src/__tests__/app/usuarios/page.test.tsx`, se generan múltiples advertencias `Warning: The current testing environment is not configured to support act(...)`. Esto ensucia los logs y puede ocultar problemas de concurrencia. La causa suele ser actualizaciones de estado en componentes React que no están envueltas en `act()` o el entorno `jest` no tiene `global.IS_REACT_ACT_ENVIRONMENT = true`.

Ubicación:
- `src/__tests__/app/login/page.test.tsx`
- `src/__tests__/app/usuarios/page.test.tsx`

3. Acciones Kaizen (Hoja de Ruta para el Executor)

### Acción 1: Corregir el entorno global de tests para React
Configurar `IS_REACT_ACT_ENVIRONMENT` para suprimir los warnings globales.

Fragmento:
En `jest.setup.js` o equivalente (como `src/jest.setup.js` o en los propios tests):
```javascript
// Configurar React act environment globalmente
global.IS_REACT_ACT_ENVIRONMENT = true;

// Mock de IntersectionObserver requerido por use-intersection en next/link
global.IntersectionObserver = class IntersectionObserver {
  constructor(callback) {
    this.callback = callback;
  }
  observe() {}
  unobserve() {}
  disconnect() {}
};
```

### Definition of Done (DoD)
- Ejecutar `npm run test:all` o `npm run test` y verificar que no haya warnings `Warning: The current testing environment is not configured to support act(...)` en los archivos reportados.
