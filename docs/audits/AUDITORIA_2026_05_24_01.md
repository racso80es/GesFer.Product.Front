## 2. Pain Points (🔴 Críticos / 🟡 Medios)
Hallazgo: Fugas en la Arquitectura Frontend (Deep relative imports)
Descripción: Se encontraron múltiples archivos dentro del directorio `src/tests/` que están utilizando imports relativos profundos (ej. `../../lib/config`) en lugar de usar el alias de ruta `@/`. Esto viola el estándar arquitectónico Frontend establecido.

- `src/tests/helpers/test-data-cleanup.ts`
- `src/tests/api/auth-api.spec.ts`
- `src/tests/api/usuarios-api.spec.ts`
- `src/tests/api/api-client.ts`

## 3. Acciones Kaizen (Hoja de Ruta para el Executor)
**1. Corrección de Imports en el directorio tests:**
Modificar todos los archivos en `src/tests/` que contengan imports relativos hacia `../../lib/...` para que usen el alias `@/lib/...`.

```javascript
// Ejemplo de Acción Kaizen:
// Buscar: import { appConfig } from '../../lib/config';
// Reemplazar: import { appConfig } from '@/lib/config';
```

**Definition of Done (DoD):**
1. Ningún archivo dentro de `src/tests/` debe contener imports relativos con `../../`.
2. El proyecto debe compilar correctamente después de los cambios.
3. Las pruebas unitarias y e2e deben seguir pasando.
